# 🌍 COVID-19 Data Visualization

> **Task 2** – HexSoftwares Data Science Internship

---

## 📋 Project Overview

This project is part of my Data Science Internship at **HexSoftwares Pvt. Ltd.** The task involves using a public COVID-19 dataset to visualize cases and deaths trends using various charts and graphs. The goal is to learn data handling, date-time formatting, and data visualization techniques.

---

## 🎯 Key Objectives

- ✅ Load and explore a public COVID-19 dataset
- ✅ Clean and preprocess the data (handle missing values, date formatting)
- ✅ Create line charts to visualize cases and deaths trends over time
- ✅ Compare COVID-19 trends across different countries
- ✅ Generate histograms and distribution plots
- ✅ Derive actionable insights from the data

## 🚀 How to Run This Project

### 1. Clone the Repository
```bash
git clone https://github.com/mdmuneebdesigns/HexSoftwares_Covid_Data_Visualization.git
cd HexSoftwares_Covid_Data_Visualization
```

### 2. Install Dependencies
```bash
pip install pandas numpy matplotlib seaborn
```

### 3. Run the Notebook
- Open `Covid_Data_Visualization.ipynb` in Jupyter Notebook or Google Colab.
- Run all cells sequentially.
